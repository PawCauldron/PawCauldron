# PawCauldron

魔獸世界插件 PawCauldron 的測試版。正式版請到 [CurseForge](https://www.curseforge.com/wow/addons/pawcauldron)。

## 下載

[Releases](../../releases) 裡標 Pre-release 的就是測試版。

- `-installer.zip`：雙擊安裝，推薦
- 另一個 zip：只有插件，自己解壓到 `_retail_\Interface\AddOns\`

## 安裝

1. 解壓縮 installer.zip
2. 執行「安裝.bat」
3. 遊戲開著也可以裝：裝的時候先不要 `/reload`，看到「已安裝好」再 `/reload`

跳出「Windows 已保護您的電腦」的話：其他資訊 → 仍要執行。

直接覆蓋原本的 PawCauldron，不留備份，WTF 不會動。想換回正式版就從 CurseForge 重新安裝。

有用 CurseForge App 的話，測試期間先別更新 PawCauldron，不然會被蓋回正式版。

## 回報

設定 → 快捷 → 訊息提示 →「複製錯誤回報」，Ctrl+C 後傳給我。
紀錄在 /reload 或登出時才會存，閃退那場記不到。
